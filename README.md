# L'Arche

Application mobile et web de mise en relation pour la garde d'animaux entre particuliers. Lutte contre l'abandon pendant les vacances via une plateforme communautaire de confiance.

## Stack technique

- **React 19** + TypeScript
- **Vite 8** — dev server et build
- **Tailwind CSS v4** — styles
- **React Router v7** — navigation

## Lancer le projet

```bash
npm install
npm run dev
```
